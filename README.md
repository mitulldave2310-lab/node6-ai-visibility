# node6 Labs AI Visibility Audit

Type a website, get a score for how well ChatGPT, Perplexity and Gemini can read and cite it.

```bash
npm install
npm run dev
curl "http://localhost:3000/api/audit?url=example.com"
```

`npm test` runs the scoring tests. See `CLAUDE.md` for architecture and rules.
